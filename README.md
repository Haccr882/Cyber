# CyberLearn — Cybersecurity Education Website

A lightweight static website containing 30 original educational cybersecurity articles.

## Before production
1. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
2. Replace the placeholder contact wording with the actual public contact method.
3. Review the Privacy Policy for the exact analytics, cookie, hosting, and advertising services you use.
4. Add your advertising network code only after you have an approved account and have checked its current policies.
5. Replace/verify any article claims that need current technical references.
6. Deploy over HTTPS and test all links on mobile and desktop.

## Important
This starter site intentionally does not include fake ad code, fake testimonials, copied material, or fabricated company claims.
